# JAXA Moon & Satellite Real-time Visualization

![screenshot](screenshot.png)

A real-time visualization of the positions of the Moon and satellites,
built in TouchDesigner using data from JAXA.

## How it works

- Data source: JAXA data on the positions of the Moon and satellites
- Python fetches the data and sends it into TouchDesigner
- TouchDesigner renders the positions in real time
